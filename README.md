# Black-Scholes Option Pricing Model

## Overview
This project explores the Black-Scholes model for pricing European call and put options using Python.

## Objectives
- Understand the mathematical foundation of option pricing.
- Implement the Black-Scholes pricing formulas.
- Explore put-call parity and the relationship between European call and put options.

## Model Inputs
- **S:** Current stock price
- **K:** Strike price
- **T:** Time to maturity in years
- **r:** Risk-free interest rate
- **σ:** Annualized volatility

## Key Concepts
The Black-Scholes model estimates the theoretical value of European options under specific assumptions.

Put-call parity describes the relationship between European call and put prices with the same strike price and expiration date.

## Technology
- Python
- Jupyter Notebook

## Project File
`Black_Scholes_NIFTY.ipynb`

## Limitations
The Black-Scholes model relies on simplifying assumptions. Actual market prices may differ because of transaction costs, changing volatility, dividends, liquidity, and other market factors.
